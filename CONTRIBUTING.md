# Contributing to Linux From Nothing (LFN) 🤝

First of all, thank you for taking the time to contribute and help make LFN better! This project is a personal educational journey, and community feedback is highly appreciated.

## How Can You Help?

### 1. Reporting Bugs & Suggesting Features
If you find a bug in the ISO scripts or a typo in the website tutorial:
* Check the [Issues](https://github.com) tab to see if someone else already reported it.
* If not, open a new Issue and clearly describe the problem, what hardware/VM you used, and how to reproduce it.

### 2. Submitting Code Changes (Pull Requests)
If you want to fix a bug or add a helpful utility script:
* Fork this repository and make your changes in a separate branch.
* Ensure your scripts are clean, well-commented, and tested.
* Submit a Pull Request (PR) with a clear description of what you changed and why.
