# Linux From Nothing (LFN) 🚀

Welcome to the official repository of **Linux From Nothing (LFN)**. 

LFN is not just another Linux distribution. It is an educational project, a custom live-ISO environment, and a comprehensive guide that allows anyone to build an independent operating system tailored entirely to their own needs.

🔗 **Official Website & Guide:** [keyfti.github.io](https://keyfti.github.io/)

---

## 💡 The Philosophy
Instead of maintaining a massive distribution with infinite package updates, LFN provides a verified starter environment (ISO) and the exact knowledge you need to build your own system from scratch. 
* **Full Control:** You choose every flag, library, and configuration.
* **No Bloat:** Zero pre-installed junk, just the raw power of Linux.
* **Pure Education:** Learn how the Linux kernel, bootloaders, and base system interact.
